# Homebrew Tap for DevCon

This tap provides Homebrew formulae for DevCon - Your Mission-Critical Dev Environment Manager.

## Installation

```bash
brew tap devconhq/tap
brew install devcon
```

Or install in one command:

```bash
brew install devconhq/tap/devcon
```

## Requirements

DevCon requires a container runtime:
- Docker Desktop, or
- Apple's Container Runtime (macOS 15+)

## Available Formulae

- **devcon** - Development container manager with multi-runtime support
